# 発動チェックポイント

`SOURCE_CONFIRMED`。対象ExpansionのSingle／Doubleでは、ハンドラがスクリプトを呼んで中断し、同じ段階または次段階に再入する。 `DoMoveEnd` は再入時に特性と品物を取り直す。表示・AIの評価は別の読者。Triple／Rotationの範囲、翼個体を有効とするか、位置変更時の発動はGC側の設計として試験する。
