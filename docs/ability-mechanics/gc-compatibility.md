# GC V19の対応台帳

`BattleAbility` は定義元ID・分類・最大4個の `BattleAbilityHook`。V11単一hook、V12リストと有理確率・フラグ、V13共通Modifier、V14固定小数点調整、V15天候、V16フィールド、V19消費型品との順序。 `battle_ability_valid` は各hookの版・引数・フラグを検証する。 `BMSRC_ABILITY` は同じ計算基盤の特性ステージに対応する。 `ResolveAbility` は対象のコードをデータへ写像する。 `RULE_STRICT_ABILITIES` は未対応分類の開始を拒否できる。非厳密で未対応を通知して進む経路と、全特性を止める `RULE_IGNORE_ABILITIES` は別。個別効果は下表で判定する。[V12〜のブロック](https://github.com/koziyagoukei/gba-gc-extension/blob/44c51538c7e5efbeb27bee91d5cc8a0a89cab14b/protocol/battle_protocol.h#L349) · [battle_ability_valid](https://github.com/koziyagoukei/gba-gc-extension/blob/44c51538c7e5efbeb27bee91d5cc8a0a89cab14b/protocol/battle_protocol.c#L428) · [厳密な開始チェック](https://github.com/koziyagoukei/gba-gc-extension/blob/44c51538c7e5efbeb27bee91d5cc8a0a89cab14b/gamecube/battle/battle_core.c#L312) · [ResolveAbility](https://github.com/koziyagoukei/PokeEm-expansion-CanuseJP/blob/2d1e107ad820a3b0a601af968b49856f74151ee1/src/frontier_gc_battle.c#L1035) · [Requestルール](https://github.com/koziyagoukei/PokeEm-expansion-CanuseJP/blob/2d1e107ad820a3b0a601af968b49856f74151ee1/src/frontier_gc_battle.c#L2706)
