# GBA-GC Extension / Frontier Hack Public Alpha v0.1.0-alpha (draft, not released)

> This is a draft. No GitHub Release has been published because the GBA patch
> could not be distributed (see [releases](../releases.md#v010-alpha-status)).

**Release 1.** Use `companion.dol` and the GBA build of the same release only;
the link check shows both numbers and a mismatch is refused.

## What you can test

- Single, Double, Triple and Rotation battles run on the GameCube with commands chosen on the GBA (second screen).
- Targeting, spread moves, Triple range and Shift, Rotation.
- Stat stages, major status (poison, toxic, burn, paralysis, sleep, freeze), end-of-turn damage.
- Switching, replacement after fainting, Struggle, Roar/Dragon Tail, U-turn-style pivots.
- Party Viewer and a link/version check, from the Cube Tester room behind the Frontier Hub's top-right door.

## Limits

- Move, ability and item compatibility is incomplete; unsupported moves cannot be chosen.
- Move animations are in development.
- Battle results in the Cube Tester are display-only.
- Only Dolphin with its integrated GBA is supported; real hardware is untested.
- Back up your normal save before testing.
