# 未確認事項と追加試験

## ACT-002の再現案（実行済み・補修済み）

**補修済み（M4-B1b補修、`milestone4b1b-act002`）。** 下の再現案を参照試験として実行した。Expansionの順は「反動メッセージ → オボン消費（70→110） → 後続行動 → 当該ターンの残留」で、再現案の予想どおりだった。補修前のGCは「`EV_RECHARGE` → 後続行動 → オボン」で、予想どおりの不一致だった。補修後は両者が一致する。詳細と試験一覧は [ACT-002](status-and-volatiles.md#act-002)。

初版の再現案（実行済み）：

1. Singleで先手に、反動待機を生む技とサンパワー、オボンのみを用意する。最大HP 160、現在HP 90、開始時の晴れ。技は命中し、相手は生き残る。相手には先手のHPを変えない技を選ばせる。1ターン目のサンパワーで90→70。この時点ではオボンを消費しない。
2. 次ターンの先手が反動待機。後手には順序が見える技を選ばせる。Expansionの期待順は `反動メッセージ → オボン消費で70→110 → 後続行動 → 当該ターンの残留`。元技PPは待機ターンに減らない。
3. 現行GCのコードから導かれる結果は `EV_RECHARGE → 後続行動`。きのみはその時点で残り、後続技の終了チェックで遅れて発動し得る。最終HPと消費有無に加え、後手行動の前後を比較する。
4. Doubleでは待機する個体とは別の味方／相手に、前ターンの日照ダメージでしきい値以下になったきのみを持たせ、全員チェックも確認する。持ち物なし、反動より先のひんし、V18、`RULE_IGNORE_ITEMS` を対照にする。睡眠・こおり・ひるみの保留きのみは個別の比較ケースにする。

実行での補足：

- 晴れの設定はExpansion側では相手のにほんばれ、Lab L72では開始時の天候ルールで行った。
- Doubleでは、待機する個体自身のきのみが味方・相手より先に発動することも固定した。
- 状態異常きのみの保留は、このビルドでは作れなかった。状態異常を付与する処理がすべてその場で持ち物を判定するためで、GCのネイティブ試験だけで確認した。
- こおり・ひるみは未比較で、睡眠だけを比較した。

一般の反動テスト `recharge.c` の1件が失敗する原因は、英語メッセージ「Wobbuffet must recharge!」の照合にある。このビルドの文字列は日本語（`{JPN}攻撃の 反動で …は 動けない!`）なので、一致する文がない。同じテストからMESSAGEを除いた版はPASSし、日本語のメッセージ照合もGC参照試験でPASSする。このテストはフロンティアの既存失敗2,455件の1件で、本補修では変更していない。

## 行動不能時の残る差

- **選択対象の状態異常を先に判定する点。** Expansionの `moveendall` は、行動者より先に `MOVEEND_ITEM_EFFECTS_TARGET` で選択対象の状態異常きのみを判定する。GCの `bc_items_after_action` は行動者から判定する。選択対象に未処理の状態異常がある場合にだけ順序が変わるが、現行の対応範囲では作れない。あばれる後のこんらんなど、未処理の状態異常を残す処理を対応に加えるときに再評価する。反動・まひ・睡眠・自傷のすべてに共通する。
- **ゲーム画面のターン表示。** GCの画面は待機ターン（2ターン目）にも「TURN 1」と表示する。これは完了したターン数で、M4-B1b以前からの表示仕様であり、今回の順序とは無関係。

## B1cで先に固定する境界

- 対象の被弾、行動者の反動／接触、技全体末尾の全員チェックを区別する。がんじょう／タスキ、消費済み品の不在、ひんしした所持者にも発動する例外を個別に試す。
- 接触反動によるひんし、タスキ消費後の次の一撃、範囲技での複数反応、ターン途中の交代を先に固定する。
- 日照特性のHP変化のように、即時判定をしない箇所がある。ターン末に全員を一括で検査すると、参照試験で確認した遅延ケースの順も変わる。

## 仕様書の拡充順

1. 行動不能と保留持ち物の参照試験を作り、コード確認を実行結果で補強。
2. 技フィールド、被弾・技末の特性と持ち物を再取得する段階、ひんし後の対象可否を監査。
3. ターン末の全ハンドラ、設置技、補充点、交代・フォーム・場の相互作用を別章にする。
4. 全ギミックの状態遷移、Triple／Rotation固有の順序、消費・交換の永続反映は個別の根拠が揃った段階で拡充する。
