# GBA-GC Extension / Frontier Hack Public Alpha テストガイド

このガイドは、プログラミングやROMハック開発の経験がない方が、Dolphin（ゲームキューブ／Wiiエミュレーター）の
内蔵GBA機能を使って **GBA-GC Extension** の対戦テストを行うための手順です。

> **現在の状況（v0.1.0-alpha）**
> GameCube側の `companion.dol` と、それに対応するFrontier Hack側のビルドは完成し、下の手順で検証済みです。
> ただし **GBA用パッチ（BPS）は配布を見合わせています**。パッチの中身を監査したところ、
> 元のゲームから派生したデータ（ゲームの再構築コード、ポケモンの画像や音声）を大量に含むことが分かったためです
> （詳細は [releases.md](releases.md)）。そのため、いまはGitHub Releaseもありません。
> パッチなしで試す方法は、自分でソースからビルドする方法（開発者向け、[build.md](build.md)）だけです。

- これは**非公式のファンプロジェクト**です。任天堂、株式会社ゲームフリーク、株式会社ポケモン、
  クリーチャーズ、Dolphinの開発チームとは一切関係がありません。
- ROM・BIOS・セーブデータ・ゲームの画像や音声は配布しません。**自分で正規に所有しているゲーム**から用意してください。
- 実機（ゲームキューブ本体＋GBAケーブル）での動作は確認していません。対象は **Dolphin + 内蔵GBA** だけです。
- テストの前に、**ふだん遊んでいるセーブデータは必ずバックアップ**してください。

---

## 1. 必要なもの

| もの | 内容 |
|---|---|
| PC | Windows 11 で検証しました。 |
| Dolphin | **Dolphin 2609b**（このバージョンで検証）。公式サイト <https://dolphin-emu.org/download/> から入手してください。 |
| GameCube側プログラム | `companion.dol`（release 1 / v0.1.0-alpha） |
| GBA側ROM | 正規に所有する **日本版『ポケットモンスター エメラルド』** に、同じリリースのパッチを当てたもの（**いまは配布停止中**） |
| セーブ | Frontier Hack を遊んで「フロンティア ハブ」に行けるところまで進めたセーブ |

ベースにするROMは次のものだけです。ハッシュは検証用のPCで実際に計算した値です。

| 項目 | 値 |
|---|---|
| ゲーム | ポケットモンスター エメラルド（日本版）、ゲームコード **BPEJ**、リビジョン 0 |
| サイズ | 16,777,216 バイト（16 MiB） |
| SHA-256 | `33f5610b9186b4add09fef68895deb00f552b997b3d133b5a961e5123506343c` |
| SHA-1 | `d7cf8f156ba9c455d164e1ea780a6bf1945465c2` |
| CRC32 | `4881f3f8` |

## 2. ROMにパッチを当てる（配布再開後）

パッチが配布されるようになったら、BPSパッチに対応したツール（例: Floating IPS、Rom Patcher JS）で、
上のベースROMにパッチを当てます。ツールが「ソースのチェックサムが違う」と言うときは、ROMが違います。
**`companion.dol` とパッチは、必ず同じリリース番号のもの**を使ってください（[releases.md](releases.md)）。

## 3. Dolphinを用意する

1. Dolphin 2609b を展開して `Dolphin.exe` を起動します。
2. はじめて起動すると「Dolphinの開発者への情報提供にご協力いただけますか？」と聞かれます。どちらを選んでもテストには影響しません。
3. ふだんのDolphinの設定と分けたいときは、別のフォルダを使って `Dolphin.exe -u <フォルダ>` で起動できます。

## 4. ゲームキューブ側の接続設定

1. ツールバーの **コントローラー** を押します（「設定」ウィンドウの「コントローラー」ページが開きます）。
2. **ゲームキューブ デバイス設定** の **ポート 2** を **GBA (内蔵)** にします。
   - 「GBA (TCP)」ではありません。
3. ポート 1 は **標準コントローラ** のままにします。

## 5. 内蔵GBAにパッチ済みROMを指定する

1. 「設定」ウィンドウの左側で **ゲームキューブ** を選びます。
2. **GBA設定** の **コントローラーポート 2 のROM** に、パッチ済みROMのパスを入力するか、右の「...」から選びます。
3. セーブは **セーブ保存先** のフォルダに、`<ROMのファイル名>-2.sav` という名前で置かれます
   （例: ROMが `frontier-gc-alpha.gba` なら `frontier-gc-alpha-2.sav`）。
   既存のセーブを使うときは、**コピー**をこの名前で置いてください。
4. 「閉じる」を押します。設定はDolphinを閉じたときに保存されます。

GBA BIOS は指定しなくても、検証した Dolphin 2609b では起動しました（ログに BIOS が見つからない旨が出ますが問題ありません）。

## 6. キー割り当て（ぶつからないようにする）

Dolphinの初期設定では、ゲームキューブのコントローラーとGBAが**同じキー**を使います
（どちらも A=X、B=Z、START=Enter、十字=T/F/G/H、L=Q、R=W）。
このままだと、GBAを操作したときにゲームキューブ側にも同じ入力が入ってしまいます。

**GBA（ポート 2）**：コントローラー設定のポート 2 の「設定」→ リセットの **既定** を押すと、次の割り当てになります。そのまま使います。

| GBAボタン | キー |
|---|---|
| A / B | X / Z |
| L / R | Q / W |
| START / SELECT | Enter / Backspace |
| 十字ボタン | T（上）・G（下）・F（左）・H（右） |

**ゲームキューブ（ポート 1）**：ポート 1 の「設定」で次のように変えます。
ボタン欄をクリックしてからキーを押すと割り当てられ、**マウスの中ボタン（ホイール）でクリックすると消去**できます。

| GCボタン | キー | 使い道 |
|---|---|---|
| A | **M** | 対戦終了のあとすぐに待機に戻る（3秒待てば自動で戻ります） |
| B | **N** | （使いません） |
| START | **P** | ゲームキューブ側からセッションを終わらせる |
| Z | D（初期値のまま） | テスト用：3秒間通信を止める（切断テスト） |
| 十字ボタン・L・R | **消去** | GBAのキーとぶつかるため |

## 7. companion.dol を起動する

1. ツールバーの **開く** を押し、`companion.dol` を選びます。
2. ゲーム画面のウィンドウに **LINK PLAZA** と `Waiting for GBA (GC Extension Mode)` が出ます。
   右上に `r1 v0.1.0-alpha` と表示されていれば、release 1 です。
3. 同時に「GBA2 | ...」というGBAのウィンドウが開き、パッチ済みROMが起動します。

## 8. GBA側の準備

1. GBAのウィンドウをクリックして、キーボード入力がGBAに入るようにします。
2. タイトル画面で「つづきから はじめる」を選び、セーブを読み込みます。

## 9. フロンティア ハブから「キューブテスター」へ入る

1. 「フロンティア ハブ」の **右上の扉**（北の壁の、いちばん右側の出入口）から入ると「キューブテスター」に着きます。
   - 左となりの階段は、これまでどおり通信ルーム（ユニオンルームなど）へ行きます。
2. 中央のカウンターにいる係員に話しかけると、テストメニューが出ます。

| メニュー | 内容 |
|---|---|
| せつぞく かくにん | ゲームキューブとつながるか、両方のリリース番号・ビルドIDが合っているかを表示します。 |
| パーティビューア | 手持ちのポケモンをテレビ側に表示します（読み取りだけ）。 |
| シングル／ダブル／トリプル／ローテーションバトル | テスト用のポケモン同士で対戦します。**結果は表示だけで、セーブには残りません。** |
| わざアニメ (じゅんびちゅう) | まだ作っていません（「準備中」と表示されます）。 |
| ハブへ もどる | ハブに戻ります。入口の階段からも戻れます。 |

## 10. ゲームキューブとつなぐ

1. メニューで項目を選ぶと、GBAが `Waiting for GameCube...` になります。
2. `companion.dol` が待機中（LINK PLAZA）なら、数秒で `GC CONNECTED` になります。
3. つながらないときは、**GBAでBボタン**を押せばいつでもフィールドに戻れます。
4. `Version mismatch` と出たら、`companion.dol` とROMのリリースが違います。同じリリースのものを使ってください。

## 11. 対戦の操作

対戦の画面はテレビ（ゲームキューブ側）に出ます。コマンドはGBAで選びます。

| 場面 | 操作 |
|---|---|
| コマンド | A：たたかう、B：降参（シングル）／やめる |
| わざ選択 | 上下で選ぶ、A：決定、B：もどる |
| 対象選択（ダブル・トリプル） | 十字ボタン：対象を選ぶ、A：決定、B：もどる |
| トリプルの端 | SELECT：センターと入れ替え（Shift） |
| ローテーション | L／R：回転してから A でたたかう |
| 控えがいるとき | START：交代（パーティ） |
| 対戦のあと | A：もどる |

対戦が終わると、GBAは自動でキューブテスターに戻り、「ほかにも ためしますか？」と聞かれます。
ゲームキューブ側は3秒後に自動で次の接続を待ちます（GCのAで、すぐに戻すこともできます）。

## 12. テストしてほしいこと

| # | 項目 | 確認すること |
|---|---|---|
| 1 | パーティビューア | 名前・画像・HPがGBAの手持ちと一致する。GBAで選んだポケモンがテレビで強調される。 |
| 2 | シングル | 勝ち・負けの両方で、結果表示のあとフィールドに戻れる。 |
| 3 | ダブル | 対象を選べる。全体わざ（「なみのり」など）が複数に当たる。 |
| 4 | トリプル | 端からセンターの反対側の端には届かないわざがある（射程）。SELECTのShiftで位置が入れ替わる。 |
| 5 | ローテーション | L／Rで回転し、前に出たポケモンが行動する。 |
| 6 | 能力ランク | 「なきごえ」などでランクが変わり、GBAに表示される（例: `SA+2`）。 |
| 7 | 状態異常 | どく・もうどく・やけど・まひ・ねむり・こおりのバッジが表示され、効果が出る。 |
| 8 | ターン終了時 | どく・やけどのダメージがターンの最後に入る。両方がひんしになることもある。 |
| 9 | 交代・ひんし補充 | STARTで交代できる。ひんしになったら控えが出てくる。 |
| 10 | Bキャンセル | わざ選択でBで戻れる。対戦中のBで降参できる。接続待ちでBを押すとフィールドに戻る。 |
| 11 | 切断からの復帰 | 対戦中にGCのZ（D）で3秒止めると、GBAは `Link lost` になり、自動で再接続して最初のターンからやり直す。 |
| 12 | 再入場 | ハブに戻って、もう一度キューブテスターに入れる。 |

### まだ対応していないこと

- **とくせい・もちもの・急所・天気・フィールド・ダイマックスなどのギミック**は計算に入りません。
- 追加効果のあるわざ（ひるみ・混乱など）、優先度のあるわざ、連続わざなどの多くは**選べません**（未対応のわざは選択肢に出ません）。
- 経験値・努力値・賞金・アイテム入手はありません。
- 4形式の結果は**表示だけ**です。HP・PPやセーブには反映されません。
- 技ごとのアニメーションはまだありません（汎用の動きだけです）。
- 実機での動作は確認していません。

## 13. 不具合を報告する

GitHub の Issues から「不具合報告」テンプレートで報告してください。

- **ROM・セーブデータ・BIOS・個人情報は絶対にアップロードしないでください。**
- 報告には、せつぞく かくにんで表示される **リリース番号とビルドID**、Dolphinのバージョン、対戦形式、
  使ったポケモンとわざ、何ターン目か、その前の操作、期待した動作と実際の動作を書いてください。
- スクリーンショットは、テレビ側・GBA側の画面だけを貼ってください。
